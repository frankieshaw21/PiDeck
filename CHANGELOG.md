# Changelog

## 0.1.0 - 2026-11-06

- Added independent persistent Pi RPC sessions sharing one project directory.
- Added Electron/React two-column desktop interface with secure preload IPC.
- Added streamed messages, tool activity, model selection, task stop, and history recovery.
- Added controlled parallelism, queueing, and cooperative single-writer coordination.
- Added Confirm, Select, Input, Editor, Notification, and Status Extension UI support.
- Added process crash handling, process-tree cleanup, session deletion, and release packaging.
